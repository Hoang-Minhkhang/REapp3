# REapp3

REapp3 is a rebuilt version of Application3.

The goal of REapp3 is to create an all-in-one desktop productivity and learning management application with a cleaner architecture, improved maintainability, and future scalability.

# Features

## TimeTable

Manage study schedules and daily plans.

### Functions

- Create timetable entries
- Edit schedules
- Organize subjects
- View learning plans
- Track study sessions

---

## Test System

A built-in examination and quiz module.

### Functions

- Multiple-choice exams
- Countdown timer
- Automatic grading
- Answer tracking
- Submit examination
- Score calculation

---

## Print System

Document printing support.

### Functions

- Print Preview
- Print Dialog
- Print Document
- Printable reports

---

## Task Management

Task planning and execution tracking.

### Functions

- Create tasks In CongViec1 
- Mark tasks as completed
- Dynamic Task Boxes
- Import task lists
- Export task lists
- Task status monitoring

---

## Progress Tracking

Monitor task completion progress.

### Functions

- Task completion percentage
- Work progress overview
- Performance monitoring

---

## User Management

### Functions

- User session display
- Current user identification
- User activity handling
